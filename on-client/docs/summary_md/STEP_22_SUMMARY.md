# 22단계 작업 요약 (케셰브 보안 Agent)

이 문서는 보안 Agent **「케셰브」**의 22단계 **「새 환경 실행과 v1.0 / 릴리스 기록」**에서 수행한 누적 재현 검증, 화면 틀 및 실행 표준 작전 기록, 데이터 보존 계획을 정리한 최종 공식 작업 보고서입니다.

---

## 1. 전체 목표 및 확정된 핵심 작전

새로운 환경의 작업 폴더에서 13단계부터 21단계까지 구축한 기능이 정상적으로 누적 재현(`cumulative_behavior`)되는지 실측값으로 검증하고, 공식 배포 규격에 맞추어 화면 틀과 실행 방식을 확정합니다.

* **화면 틀 작전**: **관제 대시보드형** (맨 위 상태 카드 4개, 아래 추이와 기록)
* **포장 형태 작전**: **포장 없이 프로젝트 폴더에서 직접 실행** (`포장 명령은 일체 실행하지 않음`)
  * 별도의 exe 패키징이나 번들러 명령을 일체 실행하지 않고, 순수 Node.js 내장 런타임으로 프로젝트 폴더(`on-client`)에서 직접 실행하는 원칙을 엄격히 준수합니다.
* **매일 쓰고 싶은 핵심 기능 3가지와 순서**:
  1. **1순위 (출근 즉시)**: **기기 준수 및 로그인 세션 상태 점검** (상단 관제 카드 1, 2)
  2. **2순위 (업무 전)**: **설치 패키지 취약점 원클릭 점검** (상단 관제 카드 4)
  3. **3순위 (수시/퇴근 전)**: **최근 보안 사건 모니터링 및 AI 원인 설명** (하단 추이 및 XDR 타임라인)

## 3. 세션 범위 일치 및 SQLite 조치 저장소 데이터 보존 계획

* **세션 범위 일치 (`cumulative_source_consistency`)**:
  * `student/extension.mjs`의 `renderIdentity`에서 세션 표기를 `현재 검증된 연결: ${sessions.data.length}개`로 정밀 수정하여 전체 세션 이력이 아닌 현재 연결 하나임을 명확화.
* **SQLite 조치 저장소 보존 계획 (`data_preservation_plan`)**:
  * `docs/STUDENT_REPRODUCTION.md`를 통해 SQLite 기반 조치 저장소(`src/actions/store.mjs`) 활성화 시의 불변 트리거 제약(`ACTION_HISTORY_IMMUTABLE`, `ACTION_VERSION_INVALID`), 백업/복원 절차 및 복원 시 기한 만료 조치 안전 차단(`ACTION_CONFIRMATION_EXPIRED`) 정책 완비.

## 5. 기다림(UNV) 목록 (정직한 지원 범위)

1. **외부 상용 AI 게이트웨이 유료 키 실시간 연동**: 수업용 AI 게이트웨이 규격을 지원하며, 실제 유료 LLM 실시간 추론은 외부 인프라 대기 상태(`기다림 UNV`).
2. **원천 SDP 집행기 실시간 격리 집행**: 실제 기업 방화벽/SDP 게이트웨이와의 실시간 토큰 인증 및 집행은 외부 시스템 준비 대기 상태(`기다림 UNV`).
3. **실시간 OSV 외부 API 대량 쿼리**: 현재 프로젝트 루트에 `package-lock.json`이 미포함된 상태이므로 실시간 CVE/GHSA 대조는 lockfile 준비 대기 상태(`기다림 UNV`).

## 6. 실행 및 검증 절차

```powershell
# 1. 실행 작업 폴더로 이동 (포장 명령 실행하지 않음)
cd on-client

# 2. 학생 구현 구문 무결성 확인
node --check student/extension.mjs

# 3. 프로젝트 폴더에서 직접 데모 실행
npm.cmd run demo
# 브라우저 접속: http://127.0.0.1:5189
```
